# 图标来源和使用边界

当前候选版本不打包第三方品牌标志或用于冒充品牌的通用图形。服务商及模型均显示中性默认图标；目录标签与型号不证明实际上游。

DeepSeek 和 OpenAI 的品牌规则要求与实际服务接入相关，当前目录标识不能验证端点；Anthropic 商标指南要求事先许可和材料批准；WorkBuddy 的公开图形规范针对分享入口。当前没有足够依据确认这些标志适用于本插件的离线分发和所有展示情境，因此均未打包。逐项研究见 [品牌条件研究](research/2026-11-01-brand-icon-permissions.md)。未来仅在适用条件可核实时加入相应标志并记录来源、版本和许可。
