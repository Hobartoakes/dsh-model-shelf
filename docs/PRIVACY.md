# 隐私与偏好保存

## 插件保存什么

浏览器 localStorage 键 `dsh-model-shelf.preferences.v1` 保存：

- `version`：偏好格式版本。
- `iconNetwork`：是否允许联网下载缺失图标，默认关闭。
- `uncommon`：用户手动移入不常用列表的 `(provider ID, model ID)`。
- `collapsed`：用户折叠的 `(列表类型, provider ID)`。
- `favorites`（1.1.0）：手动收藏的 `(provider ID, model ID)`，独立于主列表 / 不常用分类。
- `providerNotes`（1.1.0）：按服务商配置 ID 保存的账号备注，最多 120 字符；空备注不保存。

收藏和备注兼容已有 v1 数据：旧数据缺少新字段时，收藏和备注默认为空，原分类、折叠保持不变。备注只按用户输入显示，不自动读取账号身份；请勿输入密钥、密码或令牌。备注可能包含你输入的私人信息，因此也属于本地用户偏好，不会写入发布包、截图或 Git 提交。

不同服务商的相同模型 ID 会单独处理。目录暂时缺少某款模型时，不自动删除其分类偏好。

仅在新键不存在时，从早期本地原型的 `dsh-model-organizer.preferences.v1` 导入合法偏好，并尝试写入新键。旧键不删除，已有新偏好不覆盖。该迁移不会访问文件、API 密钥或其他站点存储。

## 不保存什么

本插件不保存 API 密钥、会话内容、模型调用次数、使用频率、Token 用量或账户余额，不做自动分类。

## 网络与宿主行为

联网补充默认关闭；开启后，当书架显示已识别但未预置和未缓存的图标时，请求 `https://unpkg.com/@lobehub/icons-static-png@1.97.0/light/` 下固定清单中的 PNG。服务商只会收到标准图标文件名、IP 等网络请求信息，不发送完整目录、原始模型 ID、账号备注或凭据；请求不携带 Cookie、认证头或 Referer。下载后的 PNG 放在浏览器当前 origin 的 `dsh-model-shelf.icons.v1` 中，最多 32 个、单个最多 128 KiB；存储失败时仅本次页面使用。关闭联网不会删除已缓存图标，也会中止进行中的下载。模型目录加载、模型切换以及思考强度修改使用 DSH 原有接口。宿主或服务商可能有自己的网络请求、分析或日志策略；本插件不控制或取代这些策略。

### 服务商选项

普通会话打开当前 Codex 订阅模型的面板时，书架使用宿主已有的连接向该连接器读取状态，只提取适用字段、当前值和模型能力。它不访问凭据服务，不修改认证、地址、请求头或账号池，不保存或记录完整状态、配置响应、自定义指令、会话内容或密钥，也不为判断支持情况自动发起模型请求。子代理不发新增选项 RPC。

在 Codex「服务商选项」中，改选或点「恢复默认」只是草稿。只有明确点「保存」才向连接器发送一个字段，再独立读回。三项默认值由当前 profile 的 Codex 连接器保存，其他使用它的会话也受影响；不会把它们写入书架的 localStorage。详见[字段与异常处理](PROVIDER-OPTIONS.md)。

WorkBuddy 走[自己的同源接口](WORKBUDDY-PROBE.md)。普通会话打开它的模型会读取状态；点「确认检测」才请求 WorkBuddy 向上游探测，取消不发送探测请求。改选容量或选「服务商默认」则立即请求 WorkBuddy 固定或解除该模型的容量，没有额外的「保存」。这份覆盖由 WorkBuddy 保存，不进书架的浏览器存储。隐藏的子会话不发 WorkBuddy 读写请求。

## 保存范围

点星标即更新收藏；账号备注在按 Enter 或点「保存备注」后才更新。这些更改和分类、排序等书架本地偏好属于当前浏览器、当前 origin（协议、域名和端口），不属于 DSH profile 配置文件。换设备、换浏览器或改变访问 origin 后不自动迁移。当前未实现跨设备同步；DSH 插件备份也不包含这份浏览器偏好。

## 重置与卸载

卸载书架不会清空本地偏好，也不会撤销已保存的连接器设置。要还原某项 Codex 偏好，可在适用模型下点那一行的「恢复默认」再「保存」，或使用连接器自己的设置。若需单独重置，可在当前 DSH 页面的浏览器开发者工具中，删除 `dsh-model-shelf.preferences.v1` 和图标缓存 `dsh-model-shelf.icons.v1`；若曾使用旧原型，也删除 `dsh-model-organizer.preferences.v1`，避免首次读取时再次导入旧偏好，然后刷新页面。不要为了重置本插件而清空全部站点数据，以免同时影响登录状态和其他插件。
