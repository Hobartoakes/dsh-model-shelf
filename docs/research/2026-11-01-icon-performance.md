# 离线图标合成性能记录（2026-11-01）

## 方法与结果

在同一 Windows 机器上执行 `npm run build && npm run test:browser && node tests/icon-performance.mjs`。测试以 Edge 的离线 HTML fixture 构建 13 个服务商、650 个合成模型，测量点击到最后模型行可见的墙钟时间；首次打开后同一页面关闭并重新打开五次；滚动测量包含两帧 `requestAnimationFrame`。记录了 HTTP(S) 图片请求数及图片解码数量。

| 指标 | HEAD 原始构建 | 当前工作树构建 |
| --- | ---: | ---: |
| 首次打开 | 135.7 ms | 113.7 ms |
| 同页五次再次打开 | 53.5–68.6 ms | 60.9–73.2 ms |
| 六次滚动 | 9.7–15.5 ms | 10.0–11.8 ms |
| 图片解码 | 0 | 2 / 2 |
| HTTP(S) 图片请求 | 0 | 0 |

## 限制

- 一轮非严格基准，受 JIT、系统和执行顺序影响，不能据此断言图标使程序变快或计算精确开销。
- 对照是 Git HEAD，因此**不包含**先前尚未提交的紧凑卡片布局；两者差异不只是图标。
- 当前工作树的合成目录仅触发两张 DeepSeek 图片，并非所有品牌大规模展示；不代表 650 张不同图标的性能。
- 此为 Playwright 合成目录，不代表用户真实目录或真实日常 GUI 的首次加载与滚动体验；未进行真实目录基准。
- 图标本身无需网络不代表宿主目录或模型服务无需网络。
