# 模型书架：快捷收藏与手动整理

## 已确认的目标
减少服务商很多时寻找常用模型的翻页和展开操作。
- 收藏平铺，无服务商折叠层；每条保留模型、服务商、账号备注，不合并不同线路的同名模型。
- 服务商整组移至不常用、恢复，不删除 API 配置，不切换当前会话模型。后续新增模型沿用服务商分类，收藏仍独立可用。
- 记住上次标签页。
- 主列表和不常用列表分别支持服务商手动拖动排序；收藏支持模型逐条拖动排序。
- 顺序刷新保留，新加入条目放末尾；搜索期间禁止排序，不跨列表拖动。

## 保留与非目标
保留现有单模型分类、账号备注、模型身份、搜索当前列表、键盘选取、思考强度和 WorkBuddy 容量功能。
不自动按使用频率分类或排序，不新增跨设备同步，不修改 API 配置，不调用真实模型作为验收。
演示页面仅用于布局讨论，不作为产品实现。

## 实现侧默认决定（不是用户另行指定）
- 仍使用现有 React、原生 CSS、localStorage，不增加依赖。
- 整组不常用是服务商级覆盖；保留原单模型分类。恢复服务商时解除覆盖，先前单独移至不常用的模型仍在不常用。
- 被整组移走的服务商中，单模型“移回”不可直接生效；界面明确提示先恢复服务商，提供对应入口。收藏和取消收藏始终可用。
- 无上次标签页记录的旧用户沿用当前模型所在列表；一旦手动选过标签页优先恢复该记录，包括空收藏页。
- 拖动使用独立把手，不破坏文字拖选；提供上移/下移的键盘替代操作。搜索期间两种排序入口均禁用。
- 首次排序按当前可见顺序初始化。暂时离线条目的顺序记录保留；恢复在线时回原位置。新收藏在末尾，取消后再次收藏视作新收藏。
- 移入另一分类的服务商在目标页末尾加入，其他服务商相对顺序不变。

## 可观察验收
1. 从不同服务商各收藏一个模型，进入收藏无需展开即可选取，选取传递准确的 provider/model。
2. 整组移走服务商后主列表无该组；收藏不变；新增目录模型也在不常用；恢复后原单模型分类不丢失。
3. 两个分类分别调整服务商顺序互不影响；收藏可跨服务商调整模型顺序；刷新保留。
4. 拖动和排序按钮不选择模型、不折叠分组；搜索与跨列表拖放均不改变顺序。
5. 原 v1 偏好安全迁移，存储损坏仍降级提示；最后标签页刷新及关开面板后保留。
6. 浅色、深色、窄窗口及键盘操作可用，原模型切换失败与会话锁定行为不退化。
