# 模型书架离线品牌图标设计

## 目的与范围

通过两级图标帮助定位：服务商图标位于服务商名称旁，展开后模型系列图标紧挨型号名称；收藏里的模型也显示图标。模型行避免额外缩进。同一平台不同账号共用图标，并用现有账号备注区分。

## 约束

- 完全离线，首次及后续打开均不得为图标访问网络；图标随插件打包，复用本地资源，列表不等待图标加载。
- 匹配先用已知服务商和模型 ID，再用有边界的型号规则；模糊、冲突或未知时使用统一默认图标。图标只表示目录标签，不是对服务商端点、实际上游模型或官方关系的验证。
- 不改变现有模型选择、分类、排序、备注和搜索。手动设置图标暂不实现，作为未来想法单独记录。
- 候选图标优先参考 Lobe Icons 静态资源；固定来源和版本，记录适用的项目许可、版权声明及已知品牌使用条件。软件 MIT 许可不自动证明第三方商标授权；不得将未经核实的授权或背书写成事实。具体有冲突或限制的素材用默认图标替代，不将逐一取得书面许可设为通用前提。
- 不承诺性能数值；对相同目录、环境下的更新前后首次打开、再次打开和滚动进行测量并报告。

## 方案

采用 Lobe Icons 候选资源本地打包、集中维护映射与统一默认图标；不采用只以字母生成的图标，因为辨识度较低；运行时不从网络补充图标。效果图是概念示意。已知 ID 优先，边界明确的型号规则其次；匹配结果只表示目录文字而非上游事实。此前建议逐一申请书面授权的说法过于绝对；分发前仍须据具体素材及场景核对相关规则，不宣称法律保证。
