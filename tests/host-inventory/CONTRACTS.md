# 已发布 DSH：官方包行为契约

这份证据回答的是：该版发布的前端、目录和原生选择器，能否与这份书架客户端一起完成选择、拒绝请求和交还入口？它不是 50 次 DSH 安装、整机启动或桌面验收。

- [逐版运行结果](./contracts.json)：输入哈希、每版真实包身份、发出的路由、菜单观测和未测原因。客户端版本和 SHA-256 与桌面 pilot 分开绑定。
- [发布来源清单](./matrix.json)记录 npm/GitHub 对应关系、依赖边和归档指纹；[早期补充 pins](./early-pins.json)记录从同版 Web/picker 声明得到的 runtime 与模块加载器归档。无 tag/锁的早期版本使用满足归档声明的最低已发布版本，不声称还原每个用户的安装锁。未用相邻宿主或今天的最新套件填空。
- **桌面证据另算。** [隔离 Windows rc.5 的 pilot](../artifacts/clean-0.2.2-rc.5-1795363695552-3d73b594/result.json)验证安装、停用、重新启用、卸载及点开原生菜单，8/8；它用的是旧客户端；其 tgz SHA-256 为 `f88baf4c10f821900b789913f0345f639c70858a6066df89c6bb42f633d7b6b7`。不能将它登记为本轮修后客户端或最终压缩包的桌面证据。

## 实际执行与边界

1. [归档加载器](../host-packages.mjs)从 npm 官方注册表按精确版本下载，冷/热缓存均核对预存 SHA-512 SRI、SHA-256、归档清单身份；网页只接收归档内文件。每行开独立 headless 浏览器上下文；拦截所有页面请求，不连 DSH、实时模型或账户。
2. [逐版 runner](./run-contracts.mjs)运行**该版** Web 前端的已构建 JavaScript，取得其中的 React、React DOM、Cordis、UI primitives、slots 等真实静态模块，不拿 Node 别名模拟这些代际。两个组件模型：早期从 runtime 的原始 client 工厂取得 store 与 SlotRegistry；后期从前端取得 store，并由该版 renderer 导出 SlotRegistry。核对发布的 conversation 声明后，由夹具提供相同会话父槽；未启动完整对话插件图。
3. [席位夹具](./seat-fixture.mjs)执行原生 picker 的 apply（不是只搜索符号），使用真实 Cordis 范围、目录、存储、原生注册及组件。固定两个同模型 ID、不同 provider 的虚构目录；外部 RPC、投影更新、session、命令、locale 与父级 composer 是夹具。验证完整 provider/model/effort 请求及响应后的共享状态；同一个 ID 不会掩盖路由错误。打开书架并点击另一提供方，检查请求、共享模型已变和弹层关闭；故意拒绝下一次切换，必须显示错误、保留弹层和上一个路由。addressed 子代理的 load/select 必须产生零请求。
4. **槽位归还 ≠ 按钮可用。** 先卸载书架的客户端 Cordis fiber，检查实际原生组件夺回首席；再点击原生按钮，要求展开、菜单中出现本次虚构目录、关闭后不再展开。重装书架后给它一个没有可用目录的会话；在书架仍加载的情况下，又通过真实原生按钮验证可点开菜单。存在 label 子槽时，还检查其原生声明和测试徽标注册未被替换，卸载原生 owner 后该声明消失。这里不声称渲染了桌面专有徽标；也不把客户端卸载写成 CLI 卸包。
5. 8 个早期布局**另跑**[真实前端启动结算](./boot-settlement.mjs)：应用使用该版本的 Cordis loader，从带清单边的最小启动图加载书架；没有 remote.session，正常组必须到达挂载标记。故意增加永远等不到服务的条目，必须由原始 Web 路径报告 pending；负对照防止把空载误判为启动通过。其余 38 个前端只使用组件运行边界，未验证完整 Web/Desktop 的加载顺序、投影时序、凭据、其他插件或完整宿主 Node 要求。

## 复跑

源码工作树根目录，Node 24、pnpm 12；Windows 有 Edge，其他平台提供已安装的 Chrome，或设置 `DSH_TEST_BROWSER_EXECUTABLE` 指向 Chromium 可执行文件。第一次需能访问官方 npm，之后可断开网络。不要在有人使用的图形会话上运行。本组不需要系统 DSH、模型、凭据或浏览器日用 profile。

```sh
pnpm install --frozen-lockfile --ignore-scripts
node tests/host-inventory/verify.mjs tests/host-inventory/matrix.json tests/host-inventory/legacy-pins.json
# 运行全部官方包；首次联网写入忽略的 tests/vendor 缓存。输出只写新文件。
node tests/host-inventory/run-contracts.mjs --output=tests/vendor/recheck-all.json
# 已有上述缓存：离线重跑精确版本（可替换为表中任何一个或多个版本）
node tests/host-inventory/run-contracts.mjs --offline 0.0.1-rc.5 0.1.2-alpha.2 0.2.2-rc.5 0.2.3-alpha.2
# 检查本次留档、生成同一张表；--pilot 还须本地已有对应的单独桌面记录
node tests/host-inventory/verify-contracts.mjs
node tests/host-inventory/verify-contracts.mjs --rows
# focused Node：虚拟 RPC 对写者冲突、重连/作废、两种加载顺序等的更细检查
node --test tests/host-compatibility.test.mjs tests/admission.test.mjs
# 如果需要独立重核早期 runtime/module pins：输出 JSON，不改快照
node tests/host-inventory/early-pins.mjs
```
